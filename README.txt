Para publicar no GitHub Pages:
1. Crie/abra um repositório no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Vá em Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch principal e a pasta / (root).
6. Salve e aguarde a publicação.

Os botões de WhatsApp e telefone já estão configurados com os números informados.
